**[Increment-and-Freeze](https://github.com/etwest/Increment-and-Freeze)** (2023–present)  
Fast parallel computation of LRU hit-rate curves. Being integrated into WiredTiger and OpenCilk.  
Paper: [SPAA 2023](https://doi.org/10.1145/3558481.3591085)

**[CUPCaKE](https://github.com/etwest/DynamicQueriesCC)** (2025)  
Parallel sketch-based dynamic connectivity for massive, dense graphs.  
Paper: [arXiv 2025](https://arxiv.org/abs/2509.14433)

**[Landscape](https://github.com/GraphStreamingProject/Landscape)** (2024)  
Distributed linear sketching for graph connectivity and $k$-edge connectivity.  
Paper: [ALENEX 2025](https://doi.org/10.1137/1.9781611978339.11)

**[GraphZeppelin](https://github.com/GraphStreamingProject/GraphZeppelin)** (2022)  
Graph streaming library for connected components via linear sketching.  
Paper: [TODS 2024](https://doi.org/10.1145/3643846)

**[GutterTree](https://github.com/GraphStreamingProject/GutterTree)** (pipeline hypertree) (2022)  
Parallel buffer-tree variant for batching graph-stream updates.  
Paper: [ALENEX 2025](https://doi.org/10.1137/1.9781611978339.11)
